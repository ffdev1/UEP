# UEP (Prototype)

This concept was developed as part of a team-based educational program focused on solving real-world IT cases.

A UI/UX prototype of a unified educational platform designed to centralize student data, learning progress, and interactions across multiple institutions.

## Overview
This project explores the concept of a single digital environment where students can manage their education, track progress, and interact with different organizations through one interface.

The focus is on structure, usability, and system design rather than backend implementation.

## Key Features

- Dashboard
  - Overview of platform functionality
  - Quick access to frequently used sections

- Learning
  - List of assignments and tasks
  - Progress tracking
  - Filtering system for better navigation

- Career Path (“My Path”)
  - Personalized development trajectory for each student

- Documents
  - Ability to generate and manage official documents

- Schedule
  - Unified timetable across multiple institutions

- Diary
  - Aggregated grades from different educational sources

- Organizations
  - Directory of educational institutions with detailed information

- Profile
  - User data and personal information

- News
  - Updates and announcements within the platform

## System Design Highlights

- Structured multi-page navigation
- Reusable UI components
- Filtering system across multiple sections
- Focus on scalability and user-centered design

## Notes

This project is a frontend prototype and does not include backend logic or data synchronization. The goal was to design a clear and scalable interface for a complex multi-system platform.
